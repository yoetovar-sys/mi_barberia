# Mi Barbería - Módulo para Odoo 19

Módulo personalizado desarrollado para **Odoo 19** enfocado en la gestión de turnos, clientes y servicios en una barbería.

## Características
- Registro y gestión de clientes.
- Selección de tipo de servicio (Degradado, Clásico, Barba, Servicio Completo).
- Control de tarifas y precios.
- Seguimiento de estado del turno (En espera / Atendido).
- Registro de fechas de atención.
